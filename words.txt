#
# RULES:
#   - Each word must be 2 letters up to the current grid size.
#   - Every word needs a clue after the "|".
#   - Lines starting with # are comments and are ignored, except the
#     special "GRID: NxN" line described above.
#   - Separate each PUZZLE (a group of words sharing one grid) with a
#     line containing only three dashes: ---
#   - Each puzzle needs at least 2 words, and the words should share
#     letters so they can cross in the grid. A puzzle that can't be
#     arranged into a connected grid is skipped automatically.
#
# The Daily Crossword page deals puzzles from a shuffled queue that
# alternates between grid sizes (5x5, 6x6, 7x7, 8x8 mixed together),
# and remembers (in your browser) which puzzles you've already seen so
# nothing repeats until every puzzle has been played once.
