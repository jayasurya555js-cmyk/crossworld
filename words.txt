# ==========================================================
#  CROSSWORLD  -  words.txt
#  Word list for the Daily Puzzle page (one file, four grid sizes)
#  300 puzzles per grid size = 1200 puzzles in total
# ==========================================================
#
#  HOW IT WORKS
#  - Every puzzle is a block of lines:   WORD | Clue text
#  - Blocks are separated by a line containing only ---
#  - A line like  GRID: 6x6  switches the grid size for every
#    puzzle below it, until the next GRID line.
#    Allowed sizes: 5x5, 6x6, 7x7, 8x8.
#  - Words must be 2 letters or longer and no longer than the
#    grid size (5x5 -> max 5 letters ... 8x8 -> max 8 letters).
#  - Words in a block must share letters so they can cross.
#    Aim for 4-5 words (5x5), 5-6 (6x6), 6-7 (7x7), 6-8 (8x8),
#    with at least one word as long as the grid.
#  - Lines starting with # are comments and are ignored.
#  - A block that has no GRID line above it is treated as 5x5,
#    so an older words.txt keeps working unchanged.
#  - To add puzzles, paste new blocks at the end of the right
#    GRID section (or start a new GRID section further down).
#
#  Each visit to the Daily page serves a different puzzle and
#  cycles through all four sizes before repeating anything.
# ==========================================================
