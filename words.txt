#   WORD | Clue text for that word

#   - Each word must be 2–5 letters long (the grid is a fixed 5x5).
#   - Every word needs a clue after the "|".
#   - Lines starting with # are comments and are ignored.
#   - Separate each PUZZLE (a group of words that will share one grid)
#     with a line containing only three dashes: ---
#   - Each puzzle needs at least 2 words, and the words should share
#     some letters so they can cross each other in the grid. If a
#     puzzle's words can't be arranged into a connected 5x5 grid, that
#     puzzle is skipped automatically and the rest still load.
#
# The site solves these puzzles in order, one after another. As soon
# as a puzzle is fully and correctly solved (via the Check button),
# the site automatically loads the next puzzle in this file. After
# the last puzzle, it loops back to the first one.

#   Puzzles  1-20 : Easy   (3 words each)
